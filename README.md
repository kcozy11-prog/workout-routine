# 주간 운동 루틴

개인 운동 루틴·기록 웹앱. 모든 기록은 사용자의 브라우저(localStorage)에만 저장됩니다.

https://kcozy11-prog.github.io/workout-routine/

## 휴대폰에 설치

- **Android (Chrome, 삼성 인터넷)**: 위 주소를 열면 나오는 "설치" 버튼을 누르거나, 브라우저 메뉴(⋮)에서 **홈 화면에 추가** 또는 **앱 설치**.
- **iPhone (Safari)**: 공유 버튼 → **홈 화면에 추가**.

설치하면 홈 화면 아이콘으로 열리고, 오프라인에서도 열립니다. 기록은 기기의 브라우저 저장소에 남으므로 기기를 바꾸기 전에 기록 탭에서 백업 파일을 내려받으세요.
